## What Would Need Testing (Priority Areas)

Based on the codebase structure, the highest-risk untested areas are:

**`lib/services/user_service.dart`** — Token storage, JWT refresh logic, auth header injection, login/register/logout flows. Any regression here breaks all authenticated features.

**`lib/services/transactions_service.dart`** — Order + ledger merge logic and sort order. Incorrect merging would silently show wrong transaction history.

**`lib/models/transaction_model.dart`** — `fromOrderJson` and `fromBackendJson` factory constructors interpret backend responses; wrong parsing produces incorrect amounts or statuses shown to users.

**`lib/models/vending_location.dart`** — `fromJson` has nullable-field defensive logic (lat/lng string parsing, category inference from `model_type`) that could misfire on new backend shapes.

**`lib/models/user_model.dart`** — `updateFromTransactions` points calculation, and `setBalance`/`addTopUp` mutation — wrong math directly affects wallet display.

To add tests, create a `test/` directory at project root and follow Flutter conventions:

```
test/
  models/
    transaction_model_test.dart
    user_model_test.dart
    vending_location_test.dart
  services/
    user_service_test.dart
    transactions_service_test.dart
  widget/
    sign_in_screen_test.dart
```

Standard test file skeleton:
```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:ivendapplication/models/transaction_model.dart';

void main() {
  group('TransactionModel', () {
    test('fromOrderJson parses COMPLETED status', () {
      final json = {
        'status': 'COMPLETED',
        'amount_paid_cents': 350,
        'machine_id': 'M001',
        'slot': 'A1',
        'device_order_id': 'ord-1',
        'created_at': '2026-01-01T12:00:00Z',
      };
      final model = TransactionModel.fromOrderJson(json);
      expect(model.amount, 3.50);
      expect(model.title, 'Purchase Complete');
    });
  });
}
```

For service tests that make HTTP calls, use `package:http/testing.dart` (`MockClient`) to stub responses without network access.
